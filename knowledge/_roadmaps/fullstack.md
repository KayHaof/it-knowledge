# Full-stack Developer: Angular + Spring

## Tổng quan

Từ Angular reactive UI và API contracts đến Spring transaction, security, database, testing và delivery.

## Lộ trình

1. **angular-dependency-injection** — Injector hierarchy, provider scope và lifecycle.

2. **angular-signals** — Reactive state và rendering có kiểm soát.

3. **angular-feature-workflow** — Components, forms, routing và feature boundary.

4. **angular-http-rxjs** — HTTP streams, operators, error và cancellation.

5. **angular-api-contracts** — Runtime validation và realtime recovery.

6. **source-code-architecture** — Package by feature và public API.

7. **spring-ioc-bean-lifecycle** — Backend dependency/lifecycle foundation.

8. **spring-rest-validation-errors** — REST semantics khớp frontend error taxonomy.

9. **spring-mvc-webflux** — Thread/non-blocking model của API.

10. **spring-jpa-persistence-context** — State và transaction trước wire format.

11. **sql-logical-processing-joins** — SQL mà ORM cuối cùng phải chạy.

12. **spring-postgresql-production-boundary** — Pool, timeout, migration và concurrency.

13. **security-fundamentals** — Browser và API trust boundaries.

14. **oauth2-oidc-jwt-security** — OAuth2, OIDC, JWT và token lifecycle.

15. **spring-testing-strategy** — Unit, slice, integration và contract tests.

16. **testing-strategy** — Test theo confidence/cost boundary.

17. **docker-production** — Build artifact tái lập và an toàn.

18. **secure-cicd-supply-chain** — Provenance và least privilege delivery.

19. **observability** — Quan sát flow frontend/API/data.
