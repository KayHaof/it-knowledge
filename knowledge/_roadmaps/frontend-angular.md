# Angular và RxJS: Foundation đến Production

## Tổng quan

Angular learning tree từ component/DI/reactivity đến forms, router, API contracts, resilience, testing và performance.

## Lộ trình

1. **angular-dependency-injection** — Injector hierarchy, providers, scope và cleanup.

2. **angular-component-lifecycle** — Component/template binding và lifecycle có ownership.

3. **angular-signals** — Signals, computed/effect và state derivation.

4. **angular-state-management-ngrx-decision** — Local state, signals, RxJS service và NgRx decision.

5. **angular-change-detection-performance** — OnPush, scheduling và render performance bằng evidence.

6. **angular-feature-workflow** — Feature boundary, forms, routing và state flow.

7. **angular-validation-design** — Typed forms, sync/async validation và server errors.

8. **angular-router-state-loading** — Route state, lazy loading, guards và resolvers.

9. **angular-ssr-hydration-defer** — SSR, hydration, defer blocks và browser-only boundary.

10. **angular-http-rxjs** — HTTP streams, cancellation và concurrency operators.

11. **rxjs-stream-resilience** — Error boundary, retry, multicasting và backpressure reasoning.

12. **angular-api-contracts** — Runtime DTO validation, security và realtime recovery.

13. **angular-security-xss-trusted-types** — Escaping, sanitization, CSP và Trusted Types.

14. **angular-testing-performance** — Component/integration tests và performance verification.

15. **source-code-architecture** — Package by feature và enforce public API.

16. **security-fundamentals** — XSS, CSRF, credential và browser trust boundary.
